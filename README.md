\*\*Really Sound\*\* is a powerful and lightweight Soundpad application built for gamers, streamers, and content creators. Easily play sound effects through your microphone and headphones using custom hotkeys.



\---



\## 🔥 Key Features



\* \*\*Drag \& Drop Audio:\*\* Quickly add `.mp3`, `.wav`, `.ogg`, and `.flac` files directly into the list.

\* \*\*Custom Hotkeys:\*\* Bind sounds to any key or combination (e.g., Num 1, F1, Ctrl+Alt+1).

\* \*\*Smart Audio Routing:\*\* Play audio to Microphone Only (for voice chat), Headphones Only, or Both devices.

\* \*\*Advanced Equalizer \& Boost:\*\* Built-in multi-band EQ (60Hz to 16kHz), Master Gain Boost, and a 5-level Bass Boost system.

\* \*\*Per-Sound Customization:\*\* Set independent volume, loop settings, and EQ profiles for each sound.

\* \*\*Multi-Language Support:\*\* Available in English, Ukrainian, and Russian.

\* \*\*Panic Button:\*\* Stop all playing audio instantly with one click.



\---



\## ⚙️ Setup \& Requirements



1\. Download and install \*\*\[VB-Audio Virtual Cable](https://vb-audio.com/Cable/)\*\* (Free) — required to route audio into your microphone.

2\. Launch \*\*Really Sound\*\* and go to \*\*Settings (⚙️)\*\*.

3\. Select your main Headphones and set Microphone to \*\*CABLE Input (VB-Audio Virtual Cable)\*\*.

4\. In Discord or game audio settings, set your Input Device (Microphone) to \*\*CABLE Output (VB-Audio Virtual Cable)\*\*.
